# Reef

A calm, fullscreen 16-bit ocean for the iPhone Home Screen. The view sinks from
the sunlit shallows through seven zones to a hydrothermal vent field and rises
back, over five minutes and twenty seconds.

Vanilla JS, Canvas 2D, Web Audio. No dependencies, no build step, no asset files —
every sprite is a pixel grid generated in code.

**Version:** 0.10.0

Full deploy, Home Screen and URL-parameter documentation lands at stage 13.
